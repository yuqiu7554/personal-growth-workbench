个人成长工作台隐私协议

工作台以本地存储为默认原则，不要求注册账户。任务、目标、学习、健康、复盘与资料元数据保存在用户选择的 SQLite 数据库中。

联网服务

热点与论文只访问用户启用的公开来源。启用推荐AI加工后，仅把检索到的题名、来源、日期、摘要和DOI发送给用户自己的AI服务。应用完全退出后当前版本不会联网。

密钥与附件

API 密钥保存在 macOS 钥匙串，不写入数据库或开源仓库。资料上传可选择复制到用户指定的本地资料库或仅引用原文件；统一资料库的模块索引不重复复制文件，也不会静默上传附件。

健康与复盘

健康和原始复盘默认仅保存在本机，不进入分享视图。应用不提供医疗诊断或药物建议。

用户控制

用户可以关闭模块、迁移数据库或资料库、删除凭据和本地数据。关闭模块不会删除历史资料；受管文件删除进入本地回收站保留30天，外部引用文件不会被工作台删除。

开源版本

源码仓库只包含源码、空数据库与合成示例，不包含个人记录、密钥、日志、版权论文、考试资料或第三方词典批量数据。
