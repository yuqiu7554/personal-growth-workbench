# 个人成长工作台 Notion 配套模板

版本：0.1.0  
发布日期：2026-08-16  
作者：邱昱  
项目：个人成长工作台

本目录提供两个可导入 Notion 的版本：

- `个人成长工作台-Notion模板-空白版.zip`：仅包含页面和数据库字段，适合正式开始使用。
- `个人成长工作台-Notion模板-示例版.zip`：包含少量完全合成的演示记录，适合先查看结构。

模板是桌面应用的轻量配套工具，不具备本地 SQLite、macOS 钥匙串、确定性遗忘曲线、考试评分、自动资讯/论文任务或桌面 AI 权限模型。Notion 中的数据受 Notion 服务条款和隐私规则约束。

源码与反馈：<https://github.com/yuqiu7554/personal-growth-workbench>

模板文档采用项目的 `GPL-3.0-only` 许可证发布。模板中不得包含用户个人记录、API 密钥、论文全文、考试资料、新闻正文或私人本地路径。
